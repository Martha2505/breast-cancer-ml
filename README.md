# Breast Cancer ML Models

This repository contains machine learning models trained on the Breast Cancer Wisconsin dataset. 
- **martha_model_v1**: Random Forest Classifier.
- **martha_model_v2**: Support Vector Machine.

## Installation
1. Clone this repository:
git clone https://github.com/yourusername/breast-cancer-ml.git

2. Install dependencies:
pip install -r requirements.txt

3. Run the notebook in Jupyter.

## Branches
- **main**: Contains Random Forest model.
- **alternative-model**: Contains SVM model.
